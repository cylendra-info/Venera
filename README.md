# VENERA Technology V3 — Sovereign Tech

Static bilingual multipage prototype (EN/AR). Open `index.html` or serve using `python -m http.server 8000`.

13 distinct routes per language = 26 HTML pages. Each project has its own independent page. Header logo uses the approved transparent brand asset. Home hero orbital engineering SVG is CSS animated; no heavy Three.js dependency. Reduced-motion supported.
